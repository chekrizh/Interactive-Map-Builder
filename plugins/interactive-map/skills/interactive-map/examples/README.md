# Examples

- `kutt-url-shortener.json` maps [Kutt](https://github.com/thedevs-network/kutt), an open-source URL shortener by The Devs Network, released under the MIT licence. The map describes Kutt v3.2.6 (commit `029da42`) in our own words and copies none of its code; its code links point to that commit in the Kutt repository. This project is not affiliated with Kutt or its authors.
- `privatebin-pastebin.json` maps [PrivateBin](https://github.com/PrivateBin/PrivateBin), an open-source zero-knowledge pastebin, whose own code is released under the zlib/libpng licence. The map describes PrivateBin 2.1.1 (commit `8a6312e`) in our own words and copies none of its code; its code links point to that commit. It has no `layout`: every position comes from the automatic layout. This project is not affiliated with PrivateBin or its authors.
- `fastapi-service.json` is a made-up service written for this project.
